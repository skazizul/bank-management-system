# Bank Management System

A Java console-based **Bank Management System** developed using **Core Java** concepts including **Object-Oriented Programming (OOP), Collections Framework, Exception Handling, and File Handling**.

## Features

- Create Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Transfer Money
- Search Account by Account Number
- Display All Accounts
- Save Accounts to File
- Load Accounts from File

## Technologies Used

- Java
- OOP (Inheritance, Abstraction, Interface, Polymorphism)
- Collections Framework (ArrayList, HashMap)
- Exception Handling
- Custom Exceptions
- File Handling (FileWriter, FileReader, BufferedReader)
- Enums

## How to Download

### Option 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/bank-management-system.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### Option 2: Download ZIP

1. Open this GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the ZIP file.
5. Open the project in any Java IDE (IntelliJ IDEA, Eclipse, or VS Code).

## How to Run

### Using Command Line

Compile all Java files:

```bash
javac src/BankManagementSystem/*.java
```

Run the application:

```bash
java -cp src BankManagementSystem.Main
```

### Using an IDE

1. Open the project in **IntelliJ IDEA**, **Eclipse**, or **VS Code**.
2. Run `Main.java`.
